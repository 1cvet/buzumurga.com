## 13.10.2026. Страница фриланс-работ и закрытие xfluxdev.com

**PR #4. Страница `/freelance/` и `/ru/freelance/`.**
- Работы, сделанные параллельно с корпоративной карьерой (2017-2025): Cardinals, Christicrazycake, Prodaykv23, МЫИДЕМ
  и список ранних сайтов Extra Flow. У каждой работы есть записи экрана, они открываются в плеере на странице.
- На главной в блоке «Web development (side projects)» карточка MYIDEM заменена ссылкой на `/freelance/`.
- Медиа (10 роликов `.mp4`, около 7,7 МБ) скачаны со старого сайта xfluxdev.com до его отключения и лежат в git
  (`static/assets/video/`). Взять их больше неоткуда.

**Переезд xfluxdev.com (старый WordPress-сайт студии Extra Flow).** Порядок описан в `deploy/XFLUXDEV.md`.
- xfluxdev.com уже был на этом VPS (перенесён со старого хостинга 05.10), DNS менять не пришлось.
- Перед отключением сделан бэкап на сервере в `/root/backups/` (в git его нет): дамп базы, архив файлов,
  старые конфиги nginx и PHP-FPM.
- `/etc/nginx/sites-available/xfluxdev.com.conf` заменён на `deploy/nginx/xfluxdev.com.conf`: любой адрес
  xfluxdev.com и www.xfluxdev.com отдаёт 301 на https://buzumurga.com/ru/freelance/. Сертификат Let's Encrypt
  остался и продлевается через webroot `/var/www/html`.
- Потом с сервера удалены файлы WordPress, база и MySQL-пользователь `xfluxdev`, PHP-FPM пул, системный пользователь и группа.

**PR #5. Обложки проектов в одном стиле.**
- Раньше обложки были разнородные: OG-баннер, клипарт, скриншот с телефона, сетка афиш.
- Теперь у всех одна подача: скриншот сайта в одинаковом окне браузера с доменом в адресной строке, на тёплом фоне сайта.
- Рендерит их `scripts/covers.mjs` (только для разработки, Playwright, как `scripts/og.mjs`). Живые сайты снимаются
  заново, cookie-баннеры и чат-виджеты при этом скрываются. Закрытый МЫИДЕМ берётся из `static/assets/img/myidem-640.jpg`.
  Новый проект или редизайн сайта клиента: `node scripts/covers.mjs <имя>`.
- `scripts/fetch-freelance-media.sh` удалён: xfluxdev.com больше не отдаёт файлы.

**Что остаётся владельцу:** продлить домен xfluxdev.com на 1-2 года (пока поисковики переносят вес по редиректу),
поменять ссылки в YouTube и VK Extra Flow, отправить `sitemap.xml` в Google Search Console и Яндекс Вебмастер.

## 05.10.2026. Новый сайт и переезд на VPS (PR #1, #2)

- **PR #1.** Сайт пересобран как двуязычный статический (EN/RU): один шаблон `src/page.mjs`, тексты в `content/*.json`,

- Хостинг: VPS Hetzner рядом с Kypito, nginx, папка `/var/sites/buzumurga.com`. Выкладывает только GitHub Actions
  по rsync от пользователя `deploy`, ключ ограничен папкой сайта через `rrsync`. Push в `master` = деплой.
  Подробности и правила сервера в `deploy/SERVER.md`.
- Домены buzumurga.com, www.buzumurga.com, buzumur.ga, www.buzumur.ga, все ведут на https://buzumurga.com/.
